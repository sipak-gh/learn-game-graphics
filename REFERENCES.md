# References

This file lists the sources behind the facts in this course: the Zig 0.17.1 documentation, the
raylib 6.2 source code, and the articles, papers and reference pages that the graphics chapters
build on. Each chapter has its own section, and the last line of every chapter links to it. Use
it to check a claim or to read further.

Each source has two links. **original** is the live page. **archived** is a copy in a public
archive, in case the original moves or changes:

- Web pages link to the Internet Archive's [Wayback Machine](https://web.archive.org/). A link
  with a timestamp in it opens that snapshot. A link without one opens the snapshot closest to
  today.
- Source files in Git repositories (raylib on GitHub, the Zig standard library on Codeberg) link
  to [Software Heritage](https://archive.softwareheritage.org/), which archives public source
  repositories. The link names the release tag that the course pins.

Archive links without a timestamp were built mechanically from the original URL and were not
checked one by one. If the archive has no copy, it offers to search for the nearest one or to
save the page. Every console output in the chapters comes from running the course's own code,
so the outputs are not listed here.
